# Student Performance Report Dashboard

A beginner Excel data analysis project created to practice essential Excel skills used in data analytics and reporting.

## Features

* Student marks management system
* Automatic Total and Average calculation
* Grade generation using IF formulas
* Conditional formatting for performance analysis
* Bar chart for total marks comparison
* Pie chart for grade distribution
* Clean and professional dashboard layout

## Skills Used

* Microsoft Excel
* SUM & AVERAGE formulas
* IF Formula
* COUNTIF Formula
* Data Formatting
* Conditional Formatting
* Charts & Visualization
* Data Sorting & Analysis

## Purpose

This project was built as part of my learning journey in data analytics to improve spreadsheet handling, visualization, and reporting skills.

## Tools

* Microsoft Excel
